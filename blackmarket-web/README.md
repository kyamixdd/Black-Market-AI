# Legacy Next.js source — not a production target

BlackMarket AI supports production distribution only through the Tauri desktop application in `../blackmarket-desktop/`.

This directory is retained in the current working tree as legacy/reference source. It has no production build or start scripts, is excluded from CI and desktop packaging, and has no supported deployment workflow. Do not deploy it or configure remote backend credentials for it.

The canonical desktop UI and desktop development/build instructions are in `../blackmarket-desktop/README.md`.
