# 9. BACKTESTING — CRITICAL RELEASE REQUIREMENT

The previous audit found serious backtesting integrity concerns.

Reinspect the current implementation and fix every confirmed defect.

Previously identified issues include:

- Historical simulation reading the latest live candle instead of the candle at simulated time.
- Strategy features potentially using future candles.
- Regime analysis potentially using live cached data.
- Duplicate trade accounting.
- Incorrect equity curves.
- Incorrect drawdown calculations.
- Incorrect Sharpe and Sortino calculations.
- Open positions being closed at entry price at the end of the test.
- Holdout data being included in the main simulation.
- Insufficient historical data silently passing.
- Weak tests that do not validate actual trade outcomes.
- Infinite values that may break JSON serialization.

## Required backtest integrity

A backtest must be strictly chronological.

At simulation time `t`, it may only use information that was available at or before `t`.

Implement and test:

- Historical candle cutoff
- No-lookahead signal generation
- No-lookahead regime detection
- Correct entry timing
- Correct exit timing
- Correct stop-loss behavior
- Correct take-profit behavior
- Correct fees
- Correct slippage assumptions
- Correct position sizing
- Correct leverage constraints
- Correct realized PnL
- Correct unrealized PnL
- Correct equity curve
- Correct maximum drawdown
- Correct profit factor
- Correct win rate
- Correct Sharpe and Sortino calculations
- Correct end-of-test position closing
- Correct holdout isolation
- Correct missing-data behavior

The backtest must not silently substitute live data for historical data.

If the historical dataset is incomplete, fail clearly or report the test as incomplete.

## Required deterministic tests

Create tests with known candles and expected outcomes.

Test:

1. A profitable trade.
2. A losing trade.
3. Stop-loss execution.
4. Take-profit execution.
5. Position sizing.
6. Fees and slippage.
7. Position limits.
8. Daily loss limits.
9. Multiple trades.
10. Open positions at test end.
11. Missing candles.
12. Duplicate candles.
13. No-lookahead behavior.
14. Holdout separation.
15. Equity reconciliation.
16. Drawdown calculation.
17. JSON-safe metrics.

The tests must assert exact expected values where possible.

A test such as `assert len(trades) >= 0` is invalid as meaningful coverage. Replace weak tests with assertions that prove correctness.

Do not advertise backtest performance until these tests pass.
